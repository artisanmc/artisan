## Make something your players will remember

Design inventory menus in your browser, give every item an action, and bring the result to your Paper server.

### Build your first menu

[Start with the editor](/wiki/editor/) to create a project, place items, and connect actions. Add [custom heads](/wiki/editor/custom-heads/), [composed titles](/wiki/editor/composed-titles/), and [translations](/wiki/editor/translations/) as your menu grows.

### Run it on your server

[Install Artisan](/wiki/getting-started/install-admin/): the plugin serves the editor itself, from your own server — check the [requirements](/wiki/getting-started/requirements/), then [open the editor](/wiki/getting-started/open-the-editor/).

### Configure it

Every setting is documented: [environment.yml](/wiki/configuration/environment/), [config.yml](/wiki/configuration/config-yml/), [HTTPS behind a reverse proxy](/wiki/configuration/web-server/), [resource packs](/wiki/configuration/resource-packs/), and [complete examples](/wiki/configuration/examples/).

### Run a network

Behind Velocity or BungeeCord, one server serves the editor for all the others. Read [how network mode works](/wiki/network/concepts/), then [set it up](/wiki/network/setup/).

### Extend Artisan

[Explore the developer API](/wiki/developers/) to expose data from your plugin, register commands, and build modules that work with the visual editor.
