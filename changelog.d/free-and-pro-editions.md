- **Changed**: license. Artisan is now proprietary (`LICENSE`, all rights reserved; jars licensed under the terms published with each release). The public API (`plugin/api`, `net.artisanmc:artisan-core-api`) moves to MIT, so add-ons may depend on it freely. Previously GPL-3.0 for both.
- **Added**: two editions from one code base (`docs/architecture/editions.md`). `-Pedition=free` builds the free jar (`artisan-plugin-<v>-free.jar`), `-Pedition=pro` (default) the Pro one; the workflow `Release jars` builds both with the editor on a `v*` tag and drafts a GitHub Release. In the free jar the editor shows Pro editing as reserved (title composer, image, font and Nexo import, resource pack rebuild, the readable view and preview of advanced expressions) and the hub refuses a new pack (`PUT …/resource-pack` → 403 `pro_required`). Nothing made with Pro breaks: composed titles stay shown read-only, menus render the same in game, the last pack stays served. `GET /api/v1/auth/me` returns `edition`. A module template that uses a Pro feature is logged at start (`ProFeatures`).
