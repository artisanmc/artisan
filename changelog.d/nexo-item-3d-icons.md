- **Added**: Nexo items with a 3D model (furniture, custom blocks, Blockbench models) show a 3D icon in the editor, drawn like the game's inventory does (element rotations, the model's `display.gui`, face shading), instead of one face of their texture. The server draws each model itself, once, and sends pictures with the other Nexo icons (`GET /api/v1/user/projects/:projectId/nexo-item-icons`, whose answer gains `drawn`: the ids of those items): the editor never receives a model. On a server with a large Nexo pack the models were too much to send (26 MB for 1,400 models) and the editor kept the flat textures. The Nexo configs and pack are also no longer read again on each editor load while Nexo's files are unchanged.
