- **Changed**: a data file a module's screen edits (the conversations' `data/speakers.yml`) no longer has its own row in the folder's tree: the screen's row under the module opens the module's view, where the second row opened the generic form. An old `…/data/<id>` link shows the screen's form.
- **Added**: HUD layers (API 2.20.0, `@Beta`). Artisan owns the action bar: a module shows a named layer there with `api.getOverlay().show(player, Slot.ACTION_BAR, layer, priority, text)` and `hide`s it; Artisan draws every layer together by priority and keeps them on screen, so two modules no longer erase each other. The pieces of a layer come from the same interface: `raise(text, rise)` draws text up to 128 px higher or 166 px lower, `move(px)` shifts the pen, `image(asset, rise)` draws an image of the pack at a height, `width(text)` measures text, `hasPack(player)` says whether the player's client loaded the pack. The pack always carries the rising fonts `artisan:text_up0..128` (the vanilla font textures with taller cells, `tools/minecraft-assets/gen-padded-fonts.ts`).
- **Added**: editor SDK 1.13 also brings `DocumentKindContribution.pack.images(src)`, which lists the images a kind's files draw at a height; the pack gets one font per (asset, rise), an image wider than 256 px cut into slices the plugin joins again. A 1.12 bundle still loads.
