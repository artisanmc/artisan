- **Changed**: Editor navigation follows one rule at both levels: the sidebar lists places (the
  server, now a row of its own, its modules, a module's Documents), the header the views of the
  place highlighted. The server and a module share the same header and tabs; a module's
  settings screens, its History and its settings sit under **More** in its header instead of the
  sidebar, the ⋮ menu or a gear on its row. **Test in game** is a labelled link to the server's
  Play tab.
- **Changed**: The server is no longer repeated in a module's breadcrumb: switching servers is the
  chevron on the sidebar's server row (shown with several servers), and the module's header shows
  the server's red dot only while it is down.
