- **Added**: a theme can replace a module's own image. A file `overrides/<module>/<image>.png`
  in the theme's folder (`overrides/shop/banner.png`) replaces that module's image of the name
  while the theme is in place, at the theme's size, and no other module's. The theme's image of
  a common name still replaces the common image only. Such files, reported as no longer read
  since the themes were simplified, are read again.
