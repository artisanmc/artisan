- **Added**: **Save as** in the atelier: the image open is copied under a name into a theme
  of the server, the server's own theme, a module, or a theme created on the way. The dialog
  says what the copy changes (how many menus of how many modules take it, whether the theme
  is put away, whether the place already has that name). The image you started from stays.
- **Removed**: **Copy to the common images** on a module's image, which **Save as** replaces.
  **Redraw for the server** is now **Open in the atelier**, as for any common image.
