- **Added**: The server page's Configuration edits the server's menu variants (`menu-variants`):
  name, the variant a module without a version falls back to, the conditions that show it
  automatically, whether players can choose it. A wrong entry is shown and nothing is saved.
- **Changed**: "New variant…" offers the server's variants and warns about a name the server
  does not declare. A module's display rules are labeled legacy, and an empty tree is no longer
  written to `variants.yml`: the server's variants decide.
