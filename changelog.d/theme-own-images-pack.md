- **Added**: a theme's own images. An image under `assets/` of a theme's folder
  (`plugins/Artisan/themes/<theme>/assets/`) is named `<theme>:<name>` in a menu, a title or a
  module's file, while the server holds the theme, in place or not. It enters the pack only when
  named, and shows as drawn: the themes in place do not repaint it. The editor draws it in the
  menu, says under the name which theme it is, and lists a theme's own images on its page, each
  as a menu writes it.
