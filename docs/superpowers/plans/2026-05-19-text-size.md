# Text Size Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a per-layer `size` field (one of `{4, 8, 12, 16, 20, 24, 32}`, default 8) to `text` and `textarea` title layers, so users can mix multiple text sizes in a menu title.

**Architecture:** Extend the existing `text_y{Y}.json` font-bake trick (one font variant per integer Y for arbitrary vertical positioning) with a second axis: bake `text_y{Y}_h{H}.json` for Y ∈ [-32, 172] × H ∈ {4, 8, 12, 16, 20, 24, 32}. Each variant uses vanilla `minecraft:font/ascii.png` (+ accented + nonlatin_european) with `height = vanilla_height × (H/8)` while keeping the existing ascent formula. The plugin wraps text layers in `<font:artisan:text_y{Y}_h{H}>` with `H = layer.size ?: 8`. Vanilla-text only (custom-font layers ignore the size field). No migration.

**Tech Stack:** TypeScript (editor + backend, vitest + bun:test), Kotlin (plugin, JUnit). YAML, Hono, React, Konva.

**Spec:** `docs/superpowers/specs/2026-05-19-text-size-design.md`

```ts
export function buildTextYFontJson(y: number, h: number = 8): { providers: FontProvider[] } {
  // Each vanilla bitmap provider has its own height + ascent. To shift the
  // glyph top from chest-y 6 (vanilla title position) to chest-y Y, we offset
  // the vanilla ascent by (6 - Y). The formula is identical for every
  // provider regardless of glyph height — the ascent positions the BASELINE
  // relative to the cell top, and the glyph top is then a fixed function of
  // ascent + height.
  //
  // To support per-layer text size, each bitmap provider's `height` is also
  // scaled by `h/8` (vanilla baseline = 8). MC samples the source PNG to the
  // declared height; the advance scales proportionally because MC computes
  // advance from the rendered (post-scale) pixel width.
  const shift = 6 - y;
  const scale = h / 8;
  return {
    providers: [
      // Space provider takes priority over the ascii bitmap's transparent
      // space cell, giving ' ' the same 4-px advance as minecraft:default —
      // also scaled so multi-size lines space proportionally.
      { type: "space", advances: { " ": 4 * scale } } satisfies SpaceProvider,
      {
        type: "bitmap",
        file: "minecraft:font/ascii.png",
        ascent: VANILLA_ASCII.ascent + shift,
        height: Math.round(VANILLA_ASCII.height * scale),
        chars: VANILLA_ASCII.chars,
      },
      {
        type: "bitmap",
        file: "minecraft:font/accented.png",
        ascent: VANILLA_ACCENTED.ascent + shift,
        height: Math.round(VANILLA_ACCENTED.height * scale),
        chars: VANILLA_ACCENTED.chars,
      },
      {
        type: "bitmap",
        file: "minecraft:font/nonlatin_european.png",
        ascent: VANILLA_NONLATIN_EUROPEAN.ascent + shift,
        height: Math.round(VANILLA_NONLATIN_EUROPEAN.height * scale),
        chars: VANILLA_NONLATIN_EUROPEAN.chars,
      },
    ],
  };
}
```
