> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Branch:** continue on `feat/title-composer` (SP3 not merged yet) OR cut a new `feat/sp4-bg-fonts` branched from `feat/title-composer`. Pick the branch strategy with the user before Task 1.

**Goal:** Sub-project 4 of the texture pack system. Two pieces:
1. **Custom fonts** — End-to-end font asset support: MCFonts zip import → backend pipeline → resource pack → plugin runtime. The `fontAssetId` on text layers (already in the type system) starts actually wrapping text in `<font:artisan:{font_name}>`.
2. **Full-chest background preview** — Editor mockup expands to the full chest GUI when a background layer is present, so the user sees what a 176×166 background actually covers.

**Architecture:**
- Backend accepts a MCFonts-format zip (a `font.json` + a tree of glyph PNGs) via the assets endpoint with `type=font`. Parses, validates, stores; subsequent resource pack rebuild emits `assets/artisan/font/<font_name>.json` + per-font glyph PNGs in `assets/artisan/textures/font/<font_name>/`.
- Editor: `AssetImportFontDialog` wraps the zip upload UX. `TitleMockup` is extended to know about the chest body region and renders background glyphs in it (not just the title bar). Text layers with `fontAssetId` render pixel-perfect via a Konva helper that composes glyph PNGs character-by-character.
- Plugin: `AssetCatalog.AssetEntry` carries the font's namespace. `TitleCompiler.compileLayer` wraps text in `<font:artisan:{namespace}>` when `fontAssetId` is set and resolves to a font entry.

**Tech Stack (unchanged from SP3):** Editor = React + Zustand + Konva. Backend = Bun + fflate + Drizzle. Plugin = Kotlin + Jackson + Adventure. Tests = Vitest, `bun:test`, JUnit.

## Domain types (canonical reminders)

### Asset (already in `editor/src/domain/asset.ts` — no change)

```ts
type AssetType = "texture" | "glyph" | "font";

interface Asset {
  id: AssetId;
  serverKeyId: string;
  type: AssetType;
  name: string;
  width: number;
  height: number;
  ascent: number | null;
  codepoint: number | null;
  fontMeta: FontMeta | null;     // ← populated for type=font
  contentHash: string;
  createdAt: string;
  updatedAt: string;
}

interface FontMeta {
  namespace: string;             // e.g. "artisan:my_font"; used by plugin in <font:...>
  glyphMap: Array<{
    char: string;                // codepoint in the font
    texture: string;             // path inside the bundled font, e.g. "glyphs/a.png"
    ascent: number;
    height: number;
  }>;
}
```

The fontMeta shape mirrors MCFonts' `font.json` providers (one entry per bitmap provider).

### MCFonts zip layout (input we must parse)

```
fontname.zip
├── font.json                    ← single top-level json
└── glyphs/                      ← or any path; refs come from font.json
    ├── a.png
    ├── b.png
    └── ...
```

`font.json` (subset MCFonts emits):

```json
{
  "providers": [
    {
      "type": "bitmap",
      "file": "artisan:font/mine/a.png",
      "ascent": 8,
      "height": 9,
      "chars": ["a"]
    },
    ...
  ]
}
```

Parser must:
- Accept a zip Buffer.
- Find `font.json` at root (reject zips without it).
- Each provider with `type: "bitmap"` → one entry in `glyphMap` (char, texture file path inside the zip, ascent, height).
- The `texture` path in font.json uses MC namespace syntax (`artisan:font/...`); we store only the basename so plugin/editor reconstruct paths at render time.
- Reject providers we can't bitmap-render (e.g. `type: "reference"`, `type: "ttf"`) → emit a warning per skipped provider, keep the rest.

### Task 3: Backend — `mcFontsParser` pure function

**Files (both new):**
- `backend/src/lib/mcFontsParser.ts`
- `backend/src/lib/mcFontsParser.test.ts`

```ts
import { unzipSync } from "fflate";

export interface ParsedMcFont {
  glyphMap: Array<{
    char: string;
    texture: string;       // basename stored in glyphMap, e.g. "glyphs/a.png"
    ascent: number;
    height: number;
  }>;
  /** Map of glyph file path (matching glyphMap[i].texture) → PNG bytes. */
  glyphPngs: Map<string, Uint8Array>;
  /** Warnings for providers we couldn't represent (e.g. type=reference). */
  warnings: string[];
}

export function parseMcFontsZip(zipBuf: Uint8Array): ParsedMcFont {
  const files = unzipSync(zipBuf);
  const fontJsonBytes = files["font.json"];
  if (!fontJsonBytes) throw new Error("font.json missing at zip root");
  const fontJson = JSON.parse(new TextDecoder().decode(fontJsonBytes));
  const providers: any[] = fontJson?.providers ?? [];

  const glyphMap: ParsedMcFont["glyphMap"] = [];
  const glyphPngs = new Map<string, Uint8Array>();
  const warnings: string[] = [];

  for (const p of providers) {
    if (p?.type !== "bitmap") {
      warnings.push(`skipping provider type=${p?.type}`);
      continue;
    }
    const chars: string[] = p.chars ?? [];
    const fileRef: string = p.file ?? "";
    // strip "artisan:" or other namespace prefix
    const cleanPath = fileRef.replace(/^[^:]+:/, "");
    const png = files[cleanPath];
    if (!png) {
      warnings.push(`bitmap file not in zip: ${fileRef}`);
      continue;
    }
    for (const ch of chars) {
      // multi-char strings are technically supported by MC; SP4 keeps it simple: 1 char per entry.
      if (ch.length !== 1) {
        warnings.push(`skipping multi-char entry: "${ch}"`);
        continue;
      }
      glyphMap.push({ char: ch, texture: cleanPath, ascent: p.ascent ?? 0, height: p.height ?? 8 });
      glyphPngs.set(cleanPath, png);
    }
  }
  return { glyphMap, glyphPngs, warnings };
}
```

Tests (`bun:test`):
- Empty zip → throws "font.json missing"
- Valid zip with 2 bitmap providers → returns 2 glyphMap entries + 2 PNG entries
- Provider with `type=reference` → skipped + warning
- Bitmap with missing PNG → skipped + warning
- Multi-char entry → skipped + warning

To build a test zip, use `fflate.zipSync({ "font.json": strToU8(JSON.stringify(...)), "glyphs/a.png": pngBytes })`.

router.get("/asset-font/:asset_id/:path*", async (c) => {
  const assetId = c.req.param("asset_id");
  const path = c.req.param("path") ?? "";
  const rows = await db.select().from(assets).where(eq(assets.id, assetId));
