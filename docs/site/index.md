## Make something your players will remember

Design inventory menus in your browser, give every item an action, and bring the result to your Paper server.

### Build your first menu

[Start with the editor](editor/) to create a project, place items, and connect actions. Add [custom heads](editor/custom-heads/), [composed titles](editor/composed-titles/), and [translations](editor/translations/) as your menu grows.

### Run it on your server

[Install Artisan](getting-started/install-admin/): the plugin serves the editor itself, from your own server — check the [requirements](getting-started/requirements/), then [open the editor](getting-started/open-the-editor/).

### Configure it

Every setting is documented: [environment.yml](configuration/environment/), [config.yml](configuration/config-yml/), [HTTPS behind a reverse proxy](configuration/web-server/), [resource packs](configuration/resource-packs/), and [complete examples](configuration/examples/).

### Run a network

Behind Velocity or BungeeCord, one server serves the editor for all the others. Read [how network mode works](network/concepts/), then [set it up](network/setup/).

### Extend Artisan

[Explore the developer API](developers/) to expose data from your plugin, register commands, and build modules that work with the visual editor.
