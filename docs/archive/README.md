# Archive

Documents that describe Artisan as it **was**. Read them for the history of a choice, never as
the current behavior: what is still true is in the ADRs (`docs/decisions/`) and
`docs/architecture/`.

- `specs/`: design documents from May to October 2026, kept because ADRs cite them. Many describe
  the cloud backend removed in phase F (ADR `editor-web-server`).
- `specs/main-spec.md`, `specs/web-editor.md`: the April 2026 product and editor specs (cloud
  era, `editor.artisanmc.net`, paid tiers).
- `specs/server-registry-and-derived-canvas.md`: the September 2026 server registry spec.
- `editor-ui-map-2026-05.md`: a screen-by-screen map of the editor as of 2026-05-28.

The execution plans that went with the specs (`docs/superpowers/plans/`, `docs/plans/`) were
removed on 2026-10-21; git history keeps them (`git log -- docs/superpowers/plans`).
