# Archive

`specs/`: design documents written from May to October 2026, kept because ADRs and
`docs/architecture/` cite them. They describe the product as it was when they were written, often
with the cloud backend removed in phase F (ADR `editor-web-server`): what is still true is in the
ADRs, not here. The execution plans that went with them (`docs/superpowers/plans/`,
`docs/plans/`) were removed on 2026-10-21; git history keeps them (`git log -- docs/superpowers/plans`).
